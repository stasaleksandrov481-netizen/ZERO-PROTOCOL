# Экспорт Android

Включён пресет **Android**, landscape, Compatibility, ARMv7 + ARM64, пакет `com.riftzeroprotocol.game`, версия 0.1.0. Доступ к интернету и вибрации не запрашивается. Рабочие настройки лежат в закрытом каталоге приложения.

Выбран исходный минимум API 24. В пресете указан target API 35 для локальной проверки; это не утверждение о требованиях магазина на дату будущей публикации.

## APK для внутреннего теста

1. Откройте проект в Godot **4.7.x**; предпочтительна проверенная 4.7.2.
2. Установите **Export Templates той же версии**, что редактор.
3. На ПК подготовьте JDK 17 и Android SDK. Для ветки 4.7 документация указывает Platform-Tools 35+, Build-Tools 35.0.1, Platform 35; при необходимости Gradle — CMake 3.10.2.4988404 и NDK 28.1.13356709.
4. В Editor Settings → Export → Android укажите собственные пути Java SDK и Android SDK.
5. Создайте папку `builds/` или выберите другую папку результата в диалоге экспорта.
6. Project → Export → Android → Export Project → режим debug → сохраните APK.
7. Установите APK на телефон и выполните аппаратный чек-лист ниже.

Пример команды после настройки редактора и SDK:

```bash
godot --headless --path . --export-debug Android builds/RIFT_ZERO_PROTOCOL-debug.apk
```

Используйте локальный debug-keystore, созданный штатными инструментами Godot. В архив не включены keystore, пароли, export_credentials или персональные пути.

## AAB и публикация позднее

Для AAB потребуется Gradle-сборка и соответствующий формат в экспортном пресете. Release подписывается вашим постоянным ключом. Перед публикацией отдельно проверьте актуальные target SDK, подпись, идентификатор пакета, иконки и требования выбранной площадки. Пресет сейчас предназначен для разработки фундамента.

## Аппаратная приёмка

- Первый запуск в landscape; разные повороты устройства и возобновление после блокировки.
- Все кнопки касаются пальцем; вкладки прокручиваются до калибровки.
- Системный Back: закрыть окно → вернуться в меню → подтвердить выход.
- Вырез, скругления и системная панель не закрывают значимые элементы.
- Раздельно слышны Music / SFX / UI; 0% отключает соответствующий звук.
- Перезапуск сохраняет параметры; сброс сохраняет дефолты.
- Акселерометр: наличие сигнала, нейтральное положение, знак наклона в landscape, отказ калибровки при движении.
- Низкое / среднее / высокое качество и уменьшение движения действительно меняют анимации.
- Измерить FPS, время кадра, память, нагрев и расход энергии на целевом телефоне.
