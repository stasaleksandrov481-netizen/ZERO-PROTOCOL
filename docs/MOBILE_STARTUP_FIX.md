# Пустой полигон — исправление 0.2.1

Пользовательский кадр показывал пол без Атланта и джойстиков и заголовок поверх кнопок. До исправления воспроизведена такая же поломка после исключения новых классов AtlantController, AtlantPart и VirtualHandStick из кэша, сохранённого от фундамента проекта. Godot не находил типы при компиляции скрипта полигона; UI оставался в исходных нулевых координатах, а контроллер Атланта не загружался. Логов с самого телефона нет, поэтому это подтверждённое воспроизведение соответствующего сценария, а не чтение ошибки с устройства.

Исправлены явные зависимости скриптов по res://-путям. Типы объявлены через локальные preload-алиасы. Для работы обновления больше не нужны новые записи этих классов в кэше редактора.

Расположение верхнего контейнера, заголовка и джойстиков записано непосредственно в tscn. Пересчёт раскладки происходит до настройки игровой логики и после изменения размера viewport. Если инициализация всё же завершается неуспешно, единый маршрутизатор возвращает home и показывает понятное сообщение, сохраняя возможность продолжить работу.

Проверка: тот же проект с неполным старым реестром, без открытия редактора и повторного импорта, затем графический запуск 2340×1080. Атлант и оба джойстика присутствуют, 11 физических частей загружены, заголовок расположен ниже верхней строки, игровой цикл обновляет скорость. Результаты — verification/mobile_update_result.json; реальный кадр — screenshots/mobile_update_fixed.png.

Отдельно намеренно удалён узел АТ-01: маршрутизатор вернул главное меню и открыл сообщение об ошибке. Физические тесты и прежний набор меню повторены. Предыдущий общий набор не покрывал устаревший реестр при обновлении; этот пробел исправлен новым сценарием.

Физическое Android-устройство в среде работы недоступно. Нельзя считать этот запуск аппаратной проверкой телефона.
